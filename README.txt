LEARNHUB WEBSITE - HOW TO OPEN

1. Extract the ZIP file to a folder on your Windows computer.
2. Open the LearnHub_Website folder.
3. Double-click index.html. It should open in your browser.
4. To edit the website, right-click index.html and choose Open with > Notepad, or open the folder in Visual Studio Code.
5. Keep index.html, style.css, script.js and the notes folder together.

WHAT WORKS IN THIS FRONT-END DEMO
- Responsive homepage and navigation
- Course search
- Downloadable sample text notes
- Interactive 3-question quiz with score
- Demo login modal
- Demo contact form feedback

IMPORTANT
The login and contact form are demos only. They do not create/save real accounts or send messages. A secure backend/database and email service are required for real student accounts, saved progress, teacher uploads, and live data.
To add PDFs, copy them into the notes folder and add a link in index.html, for example:
<a href="notes/my-notes.pdf" download>Download my notes</a>
